# Project REMO Logo V4

This series is based on `Project REMO logo v1.png`. The original PNG is not overwritten.

## Design Rules

- Preserve the original identity: shutter aperture + underwater wave + `Project` / `REMO`.
- Keep `REMO` large, black, heavy, and geometric.
- Use cyan only for the water element.
- Avoid adding new unrelated product symbols.

## Files

- `remo-v4-primary-optimized.svg` - main white-background logo.
- `remo-v4-primary-transparent.svg` - same primary layout without a background.
- `remo-v4-symbol-color.svg` - standalone shutter/wave symbol.
- `remo-v4-stacked.svg` - stacked vertical version.
- `remo-v4-reverse-dark.svg` - dark-background reverse version.
- `remo-v4-mono-black.svg` - one-color black version.
- `remo-v4-preview.html` - preview sheet.
